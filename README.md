## МОДЕЛЬ АНАЛИЗА И РАСПОЗНАВАНИЯ НОМЕРОВ АВТОТРАНСПОРТА ДЛЯ ДОПУСКА НА ТЕРРИТОРИЮ УНИВЕРСИТЕТА<br>
<br>
Система компьютерного зрения для автоматического обнаружения и распознавания государственных регистрационных знаков автомобилей на изображениях и видеопотоке. Проект предназначен для использования в качестве программной основы системы контроля доступа автотранспорта на территорию университета<br>
<br>

**Описание проекта**<br>
<br>
Проект реализует полный цикл распознавания автомобильного регистрационного номера:<br>
1. получение изображения или кадра видеопотока;<br>
2. обнаружение области регистрационного номера;<br>
3. выделение и предварительная обработка номера;<br>
4. сегментация отдельных символов;<br>
5. распознавание символов с помощью нейронной сети VGG19;<br>
6. постобработка и формирование итоговой строки номера.<br>
<br>
Полученный номер может использоваться для последующей проверки наличия автомобиля в базе разрешённых транспортных средств и принятия решения о предоставлении доступа.  
<br>

**Используемые технологии**<br>
<br>
- Python<br>
- PyTorch — обучение и использование модели распознавания символов<br>
- Torchvision — архитектура VGG19<br>
- Ultralytics YOLO — обнаружение автомобильных номеров<br>
- OpenCV — обработка изображений и сегментация символов<br>
- Pillow — работа с изображениями<br>
- NumPy — обработка массивов данных<br>
- Tkinter — графический интерфейс приложения<br>
<br>

**Для работы проекта требуется**<br>
<br>
- Python 3;<br>
- PyTorch;<br>
- Torchvision;<br>
- OpenCV;<br>
- Ultralytics;<br>
- Pillow;<br>
- NumPy.<br>
<br>
